# 第一人称视角与参数

可在「设置与操作」的「作战视角」中选择「第一人称」，或在存活、可操作时按 **V** 在第一人称和俯视之间切换。首次启动仍使用俯视；视角选择和参数自动保存在 `user://settings.cfg` 的 `[game]` 区段。

第一人称使用透视镜头、锁定鼠标和屏幕中心准星。WASD 相对于当前水平朝向移动；鼠标控制左右转向与上下俯仰；右键稳枪，同时缩小 FOV、降低鼠标灵敏度和移动速度。原有射击、换弹、跳跃、武器切换、购买、背包和投掷按键继续使用。滚轮仅调整俯视镜头范围。

打开购买、背包、暂停或设置界面时释放鼠标，关闭后恢复。切出窗口会暂停并释放鼠标；切回后按「继续行动」恢复。暂停、失焦和回合结果期间停止持枪视口渲染，暂停和结果期间不能通过快捷键或 HUD 消耗投掷物、切换武器。死亡后使用原有俯视观战，训练重生和新回合恢复所选视角并清零俯仰；主菜单和地图预览保持各自的镜头，重新进入游戏时恢复玩家选择。

## 镜头、射击与显示

射击从当前眼部相机沿中心准星方向发出，包含垂直方向，可命中高处或低处的敌人。墙体仍阻挡子弹；水平和垂直散布沿瞄准方向计算。投掷物从眼部沿当前三维朝向投出，并加上抛物线初始上抬。

第一人称显示完整建筑，关闭俯视剖切和扇形遮罩。角色可见性改用相机视锥以及眼部到目标身体或头部的真实遮挡检测，保留烟雾遮挡。隐藏自己的世界角色模型；持枪模型和双臂在独立视口中渲染，拥有独立 FOV，并跟随武器切换、稳枪、移动、转向、射击和换弹状态。

单发后坐力使镜头上跳，也驱动枪械动画；下一发仍跟随上跳后的中心准星方向。将 `fp_recoil` 设为 0 可以关闭该镜头与持枪反馈，武器目录定义的散布、移动散布和连射扩散继续生效。第一人称和俯视共用角色移动、武器数据、弹药、伤害、购买及回合规则。

## 参数表

所有数值都可在设置界面通过滑块或数字框修改。角度使用度，世界距离使用米，准星尺寸使用逻辑视口像素。按「恢复第一人称默认值」会重置下面 26 个 `fp_` 参数，保留当前视角、音量、全屏和俯视设置。

| 参数 | 默认值 | 允许范围 | 作用 |
| --- | ---: | --- | --- |
| `view_mode` | `top_down` | `top_down` / `first_person` | 玩家视角；不属于恢复默认按钮的重置范围 |
| `fp_fov` | 75 | 50–100° | 场景垂直 FOV |
| `fp_ads_fov` | 55 | 30–90° | 右键稳枪时的垂直 FOV，自动限制为不大于基础 FOV |
| `fp_sensitivity` | 0.12 | 0.02–0.5°/像素 | 鼠标每移动一像素的转角 |
| `fp_ads_sensitivity` | 0.65 | 0.1–1 | 右键稳枪时的灵敏度倍率 |
| `fp_invert_y` | 关闭 | 开 / 关 | 反转鼠标上下方向 |
| `fp_smoothing` | 0 | 0–30 /秒 | 0 为即时响应；正值使用平滑跟随，数值越大越快 |
| `fp_pitch_up` | 89 | 30–89° | 最大上仰角 |
| `fp_pitch_down` | 89 | 30–89° | 最大下俯角 |
| `fp_eye_height` | 1.5 | 1.2–1.6 m | 相机相对于玩家脚底的眼高，也影响射线起点 |
| `fp_near` | 0.03 | 0.01–0.1 m | 场景近裁剪距离 |
| `fp_far` | 240 | 100–400 m | 场景远裁剪距离；不改变武器射程 |
| `fp_viewmodel_fov` | 65 | 40–100° | 独立持枪相机的垂直 FOV |
| `fp_weapon_x` | 0.24 | −0.4–0.4 m | 持枪水平偏移，正值向右 |
| `fp_weapon_y` | −0.22 | −0.5–−0.05 m | 持枪垂直偏移，负值向下 |
| `fp_weapon_z` | −0.38 | −0.8–−0.2 m | 持枪前后偏移，负值向前，越小越远 |
| `fp_weapon_scale` | 1 | 0.5–1.5 | 持枪模型与双臂缩放倍率 |
| `fp_bob` | 0.015 | 0–0.05 m | 行走时的眼部与持枪晃动幅度，0 关闭 |
| `fp_bob_speed` | 10 | 4–18 rad/秒 | 行走晃动相位速度，随移动速度变化 |
| `fp_sway` | 0.4 | 0–2 | 鼠标转向时的持枪摆动强度，0 关闭 |
| `fp_recoil` | 0.6 | 0–2°/发 | 单发镜头上跳与持枪反馈，右键稳枪时镜头上跳较小 |
| `fp_recoil_recovery` | 10 | 2–25 /秒 | 后坐力指数回正响应，越大恢复越快 |
| `fp_crosshair_length` | 7 | 2–16 px | 准星线段长度 |
| `fp_crosshair_gap` | 4 | 0–12 px | 准星基础中心间距 |
| `fp_crosshair_width` | 2 | 1–4 px | 准星线宽 |
| `fp_crosshair_dynamic` | 开启 | 开 / 关 | 随当前武器散布扩大准星 |
| `fp_crosshair_dot` | 关闭 | 开 / 关 | 显示准星中心点 |

加载旧配置会补全缺失的第一人称参数；无效视角、错误类型和非有限数值回退默认值，越界数字限制在允许范围。手工编辑配置中的有效小数不会被强制对齐滑块步长。参数的唯一默认值和范围定义位于 `scripts/first_person_settings.gd`。

## 验证

`tests/first_person_test.gd` 实例化真实主场景，关闭自动对局推进，在地图外添加独立原生碰撞场地。覆盖参数迁移和限制、鼠标灵敏度与俯仰、平滑、独立持枪 FOV 与切枪、中心射线与高差射击、低掩体和实墙、视锥、上下投掷、WASD 横移、右键稳枪、模态鼠标释放与恢复、V 切换、死亡重生、新回合、菜单和地图预览恢复。额外验证暂停、失焦、回合结果时的视口停用与恢复，以及暂停/结果期间键盘与 HUD 投掷、切枪操作的阻断。

```powershell
# 原生窗口：包含鼠标捕获、WASD、右键与 V 键检查。
& 'C:/Program Files/Godot/Godot_console.exe' --path . --audio-driver Dummy --script res://tests/first_person_test.gd --resolution 1280x720

# 无窗口：验证场景与物理，明确跳过依赖鼠标捕获的输入组。
& 'C:/Program Files/Godot/Godot_console.exe' --headless --path . --audio-driver Dummy --script res://tests/first_person_test.gd
```

2026-09-17 使用 Godot 4.6.3 完成验证：无窗口模式 75 项通过，输入组明确跳过；Windows / Forward+ / Vulkan 原生窗口 87 项通过，0 失败、0 跳过。结果写入 `artifacts/first_person_results.json`，含主逻辑与配置文件 SHA256、参数快照及逐项结果。测试结束和超时退出时恢复用户配置文件的原始字节以及鼠标模式。

这些检查验证真实场景逻辑、原生物理和输入状态。它们不对渲染像素作图像断言，也不代替实际游玩的鼠标手感与画面检查。
