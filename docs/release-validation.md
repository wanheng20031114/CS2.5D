# Windows 试玩包验证

2026-09-13，使用 Godot 4.6.3 Windows x64 Release 模板导出，运行入口为 `Mirage.exe`，数据包为相邻的 `Mirage.pck`。

## 地图与控制器

- 原 Mirage 世界网格、实体变换及碰撞逐项比对通过，详见 `placement-audit.md`。
- 22 条真实角色行走路线通过：双方前 5 个实际出生点各到 A/B，以及 A↔B 回防。66 条出生点图连接非空。
- 台阶、超过步高的障碍与低天花板共 8 项限制测试符合预期，详见 `controller-validation.md`。
- 高墙、棚布及高处道具沿整个朝向扇面剖切，同时移除镜头前景对扇面的遮挡；真实碰撞、射线遮挡及源位置不变。96 项 GPU/物理检查通过，见 `view-validation.md`。

## 对局与界面

- 55 项实际主场景玩法集成检查通过，覆盖买枪、弹药、拾取、遮挡、伤害、回合及重生。
- 32 项鼠标、键盘经过实际 Godot 界面分发的检查通过。
- 主菜单新增地图预览，支持旋转、平移、缩放、五个点位定位、正交/透视切换；完整模型显示不使用游戏剖切。真实输入和退出后再次开局均通过，详见 `view-validation.md`。
- CT/T 两种玩家阵营各模拟 210 秒，均出现交战、伤害与回合流转；CT 场景另观测到 C4 安放。T 测试中的人类玩家保持出生点待命并持有 C4，因此不要求 T 场景自动安放。
- 加速对局测试使用静音接收节点，避免模拟时钟快于音频混音时钟引起退出时残留播放实例；正式游戏仍使用实际合成音频，原生界面测试运行实际音频节点。
- 新增视野和预览前的源码渲染采样为 RTX 3080、1440×810、4 名角色的自由练习：上限 60 FPS，600 帧实测约 59.997 FPS。该样本不是预览模式的性能测量；完整范围和帧时间见 `runtime-validation.md`。

## 导出包独立启动

已直接运行导出的 EXE，以 Vulkan / Forward+ 进入自由练习并运行 180 帧，退出码 0，错误日志为空。

另仅复制 EXE 和 PCK 到项目外新建的临时目录，从该目录以 headless 模式进入自由练习并运行 180 帧，退出码 0，错误日志为空。此检查确认运行资源来自导出包，而非依赖项目源目录。用户直接运行 EXE 即可；不需要传入 Godot 编辑器参数。

验证日志保留在源码项目的 `builds/logs/release-render.*.log` 与 `release-portable.*.log`。这里记录的是 Windows x64 本机验证，不代表其他系统、所有显卡或全部战术路线均已覆盖。
