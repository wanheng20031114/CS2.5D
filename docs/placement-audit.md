本次测量直接读取本机 CS2 build 25218825 的 de_mirage.vpk，经 Source 2 Viewer 20.0 导出世界、实体和独立 world_physics.vmdl。没有用 NAV 留白推测建筑或箱子的位置。

原始渲染网格：3524 个 draw call / 1,294,003 三角面。独立世界碰撞：41 个材质/碰撞分组，133,131 三角面；实体碰撞：174 个形体。

## 坐标与索引核验

Source → 本项目：`x=(sx+670)×0.0254; y=(sz+256)×0.0254; z=(-sy-847)×0.0254`。
Source2Viewer 的 GLB 轴顺序为 `(Source Y, Source Z, Source X)`，已以 3 个独立实体的 origin 与 GLB node 变换交叉验证，最大误差 0.000008609 米。
一个 aggregate 的多个 draw call 共用 POSITION 顶点缓冲。每件物体的范围必须先按 indices 筛选实际引用的顶点；直接使用 accessor.min/max 会把单个箱子的范围错误扩展到整图。`source_props.json` 全部范围均按引用索引测量。

## 碰撞分类

实体中的 func_bomb_target、func_buyzone、env_cs_place、post_processing_volume 和 func_nav_markup 是触发/元数据体，禁止作为全实心碰撞。playerclip/npcclip 用于人物阻挡，不能同时作为遮视野与挡弹墙；csgo_grenadeclip 只用于投掷物。passbullets 标志需要独立保留。每个世界和实体形体的原始 SurfaceProperty、InteractAs 与建议用途均保存在 JSON。

依据：[Source 2 Viewer 命令行文档](https://s2v.app/ValveResourceFormat/guides/command-line.html)、[地图导出说明](https://s2v.app/ValveResourceFormat/guides/exporting-maps.html)。工具解析基于逆向格式；本报告验证几何位置、范围和标志，不声称完整还原 Source 2 的全部渲染与穿透规则。

## 实体启用状态

仅保留每个导出模型的三角面还不够：必须同时读取 CS2 实体数据中的 StartDisabled、solidity、solid。原版 Mirage 包含 retake 模式专用封路体，普通爆破模式初始禁用；忽略这一状态会在 A/B 出入口生成不该出现的墙。
按源实体类别与三维 origin 匹配物理节点，最大位置匹配误差 0.000013115 米。明确排除 29 个 startdisabled 的 retake func_brush、6 个仍显示但 solidity=1（Never Solid）的 func_brush，另有 3 个 solid=0 的动态道具物理形体（布帘与两个尚未启用的破损百叶窗残余模型）。共 38 个物理形体、928 个面不参与普通模式碰撞；17 个初始禁用的渲染节点也不显示。
原始状态、实体编号、模型路径、匹配误差及各排除节点清单全部保存于 JSON。物理模型仍保留在源记录中，以便审计，未移动地图物体。普通爆破中有效的可破坏金属封板保持启用；破坏后状态需由游戏交互单独处理。
枚举与启停行为可参考 Valve 的公开 [CFuncBrush 定义](https://github.com/ValveSoftware/source-sdk-2013/blob/master/src/game/server/modelentities.h) 与 [实现](https://github.com/ValveSoftware/source-sdk-2013/blob/master/src/game/server/modelentities.cpp)；本图启用状态和数值本身来自当前 CS2 实体导出，而非旧游戏地图。
