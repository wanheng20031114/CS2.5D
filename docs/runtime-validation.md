## 输入结果：32 项通过，0 项失败

- 主界面正确显示，鼠标可以选择自由练习，并分别以 CT、T 开始游戏。
- 自由练习创建玩家与 3 名敌方 Bot。

环境为 Windows、Godot 4.6.3、Intel Core i9-10900KF、NVIDIA GeForce RTX 3080；窗口 1440×810，逻辑视口 1600×900，Forward+ / Vulkan，镜头范围 24 米。渲染的是已经导入的 Source 地图几何与源物理碰撞版本，外加当前卡通角色与界面。

输入流程和截图结束后，先进行 4 秒实际时间的运行预热，避免截图回读或场景初始化污染定期刷新的引擎性能计数。随后记录短时间原配置样本，再以 `Engine.max_fps = 60` 进行 600 帧的稳定性样本，结束后恢复原来的帧率上限。
